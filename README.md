# CampusTask

CampusTask adalah aplikasi web untuk membantu mahasiswa mengelola tugas kuliah.

## Fitur
- Menambahkan tugas
- Mengedit tugas
- Menghapus tugas
- Menandai tugas selesai
- Menyimpan data menggunakan Local Storage

## Teknologi
- HTML
- CSS
- TypeScript
- Vite
- Git dan GitHub

## Menjalankan Aplikasi

```bash
npm install
npm run dev
